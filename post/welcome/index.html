欢迎来到 GuLab（gulab.cn）。

本站是我（东南大学 顾洪成）的个人主页，目前主要包含四块内容，可通过顶部导航随时切换：

内容分区#

研究#

介绍我的研究方向：超结构材料、神经微电极、磁控微机器人，包含设计、制造与应用层面的简述；论文信息可进一步查看 Google Scholar / ORCID。

课程#

收录我面向本科生主讲的课程资料：生物系统建模与分析、生物材料学。

博客#

博客是本站内容更新最频繁的地方，主要分享科研与效率工具，例如：

  • 软件与技巧：Anki、macOS、文件格式与编码等实用教程；
  • 3D 打印：STL 格式、路径规划、结构建模等资料；
  • 建站记录：从 Hexo 迁移至 Hugo 的过程与踩坑经验。

博客文章已由旧站（Hexo）陆续迁移至此，内容仍在持续整理与增补中，欢迎关注。

归档与搜索#

  • 想看全部文章的按时间列表，前往归档；
  • 想按关键词检索，可以使用站内搜索，无需第三方服务；
  • 想订阅更新，可收藏博客首页的 RSS 链接。

关于我#

更多个人介绍与联系方式见关于页面；研究上的合作、课程上的疑问，都可以通过页面上的邮箱与我联系。

更新与维护#

  • 本站基于 Hugo + PaperMod 构建，静态托管于 GitHub Pages；
  • 文章内容如有错误欢迎指正，我会尽量及时修订并在文中标注。

祝你浏览愉快。
