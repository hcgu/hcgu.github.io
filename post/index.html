Anki最简教程

本教程在 Windows 10 企业版（版本号 1909，64 位）上测试通过。macOS/Linux/Android/iOS 请自行测试。提示：iOS 版本需付费。 下载最新版 Anki 软件 官网：英文，最新版，下载慢 Anki 中国：中文，镜像，有滞后，下载快 安装 直接双击安装即可。可能会提示 “OpenGL” 错误等信息，如忽略不影响使用，则不必处理。 安装成功后打开软件即可看到主界面。 注册账号并登录 点击同步，弹出注册界面； 用刚注册的账号登录； 如果服务器（网页）端已经存放了记忆库（又称牌组），则首次登录时自动同步到本地。 新建记忆库（或牌组） 新建记忆库、牌组，命名为 “demo”； 在新记忆库、牌组 demo 中添加卡片：卡片正面为提示内容，如 “傅里叶级数公式”；卡片背面为答案。可使用 LaTeX 语法输入公式（需提前配置 LaTeX 编译环境），也可直接粘贴图片； 可持续添加新卡片，卡片内容可以为文本、公式、图片、音频、视频、网页等； 可自定义卡片的模板。 使用 选择记忆库/牌组，点击开始学习； 卡片默认显示正面，即提示内容； 根据提示给出你的答案，答案给定后，点击显示答案； 检查你的答案是否正确：如果顺利/正确，则 Anki 会在 4 天后复习；如果犹豫/想起，则 10 分钟后复习；如果生疏/错误，则 1 分钟后复习。 这种设置基于艾宾浩斯遗忘曲线理论，用户可根据自己的情况，对参数 “1 分钟/10 分钟/4 天” 进行调整。 忠告 Anki 只是工具，没有任何神奇功能，只有善于使用、勤奋刻苦，才能有效辅助记忆； 内容至上。知识点/错题随手一拍即可复习，痴迷卡牌外观没有意义； 九层高台，始于垒土。超市排队、食堂吃饭、课间无聊时，不妨选择 Anki，而不是微博。

macOS开启硬盘NTFS读写功能

已在 macOS 10.13.6 和 TOSHIBA 移动硬盘测试通过；以下操作仅供测试，操作前建议备份数据。 APFS 格式的 macOS 系统默认隐藏了 NTFS 写入功能，一般通过安装 Paragon NTFS、Mounty 等第三方软件来获得读写功能。本教程给出通过 /etc/fstab 挂载方式直接读写 NTFS 的解决方案。 操作步骤 接入 NTFS 格式的移动硬盘，记录卷标，如 TOSHIBA； 在 Terminal 中输入： sudo vi /etc/fstab 按 i 进入编辑模式，输入： LABEL=TOSHIBA none ntfs rw,auto,nobrowse 分别按 ESC、:wq 保存并退出修改； 重启 macOS，前往文件夹 /Volume/TOSHIBA，检查读写性能。 注意事项 偶尔会发生写入项目（如 file.zip）变成灰色，且拷贝时提示 “不能更改 xx 中的一个或多个项目，因为它们正在使用中” 的警告信息。在 Terminal 中输入： xattr -d com.apple.FinderInfo file_path 其中 file_path 为 file.zip 对应的目录，灰色文件恢复至正常即可。

M文件使用UTF-8编码

测试环境：Windows 10，64 位专业版；MATLAB 2019a。 1. 在 MATLAB 命令行窗口输入命令，检查当前编码方式是否为 UTF-8： feature('locale') 2. 如果为 GBK 或 GB2312 等格式，则进入 MATLAB 的 bin 目录，复制 lcdata_utf8.xml 到桌面，并修改如下： 删除 <encoding name="GBK"> <encoding_alias name="936"> </encoding> 修改以下内容 <encoding name="UTF-8"> <encoding_alias name="utf8"/> </encoding> 为 <encoding name="UTF-8"> <encoding_alias name="utf8"/> <encoding_alias name="GBK"/> </encoding> 3. 保存上述修改，文件重命名为 lcdata.xml，复制（覆盖）到 bin 目录下； 4. 重启 MATLAB，检查并确认是否设置成功。
